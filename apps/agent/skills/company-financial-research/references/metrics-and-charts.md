# 数据底稿与表图规则

## 指标底稿

每个数值保留 metric、会计年度/期间起止、annual/h1/q1/q3、数值、原始单位/币种、合并/母公司口径、实际/预测、来源与物理页码。收入与利润是期间流量，资产/负债是期末存量；不能把半年现金流与全年利润直接比较。优先最新已披露且同口径的重述比较值，发生冲突保留双方来源；未确认重述时标记冲突而不静默覆盖。

## 常见指标与图表

| 分析 | 常见指标 | 适合的展示 |
| --- | --- | --- |
| 经营规模 | 营收、归母/扣非利润 | 年度柱图、同期间对比表 |
| 增长 | 营收/利润同比、量价变化 | 同比趋势线，明确百分比轴 |
| 盈利 | 毛利率、归母净利率、销售/管理/研发费用率 | 百分比趋势图、百分点变化表 |
| 现金 | 经营现金流、资本开支、利润 | 同期间分组柱图与解释 |
| 业务结构 | 分产品/地区收入、占比、毛利率 | 堆叠柱图、分部对照表；统一口径 |
| 投入 | 研发费用/投入、资本化率、产能 | 金额与比例分开呈现 |
| 资产质量 | 应收/存货、减值、现金/有息债务 | 趋势或结构表；周转需平均余额 |
| 风险 | 审计意见、客户集中、担保/质押、关联交易 | 有来源的风险/验证清单 |

这些是分析菜单，不是每家企业都必须画同一套图。程序已提供核心金额/同比、营业成本与毛利率、资产负债、研发费用/投入及占比，还有产品/地区/行业收入结构；模型依据实际证据自主选择，并放在相关章节。具体缺数据的指标要说明，不能因为没有原始Excel就放弃从原文取数。

产品、地区、行业是不同划分维度，分别计算，不能相加。占比的分母是同期合并营收；只拿到部分业务时，差额标为“其余收入（总额扣除）”，不能把已知业务强行归一为100%。分类名称变化保留原口径，不暗自拼接；不同来源数值冲突排除并注明。研发费用与研发投入分别展示，不能当成两项相加或混用算增速。

## 计算与可比性

- 同比：同币种、同合并口径、相同期间长度的本期与上年同期。上期为正时 `(本期/上期-1)*100%`；上期为零时不可计算。上期负值时默认展示绝对变化和“扭亏/亏损变化”等说明，不给容易误读的常规百分比。
- 半年与半年比较，前三季度累计与上年同期累计比较；不能与全年连成同比趋势。单季由累计值相减需要两期相同口径，不能把累计增速当单季增速。
- 比率变化用百分点；CAGR仅对正起终值和明确年数计算；分母为零、缺失或不可比时保留缺口。
- 金额先标准化为元，显示可转万元/亿元；期间、币种、实际/预测不可悄悄切换。归母净利率是归母利润/收入的计算口径，不与合并净利润率混写。
- 折线保留时间顺序，缺失点断开；柱图零基线，负值向下。实际与预测分开展示，不能把估计补成实际。
- 图表有标题、期间、单位、图例和可点击来源；对应数据表能核对每个数值与同比公式。没有数据时不画装饰图，不从曲线目测精确金额。

## 验收

同一底稿驱动正文取数、表格和图表；至少核对单位、列序、同比基数、缺失、负基数、重述冲突、来源页码。读图属于辅助证据，不等于独立审计；标明检查过的物理页，禁止以少量页面视觉检查宣称全本图片已理解。
