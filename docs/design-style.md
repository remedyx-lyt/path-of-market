# 前端设计风格

## 总方向

Path of Market（市场之路）的前端采用黑白极简风格：大留白、高对比、强字体、清晰分区。整体感觉应当像专业工具操作台，而不是花哨的 AI 产品落地页。

参考风格：黑白、简洁、直接、工具感强，类似 Easy Farm 页面截图。

固定参考图：`docs/assets/easy-farm-style-reference.png`

## 视觉关键词

- 黑白为主，不做彩色渐变。
- 高对比，文字清楚，按钮明确。
- 大字号标题，强视觉重心。
- 大面积留白，界面不拥挤。
- 深色信息卡片用于承载关键数据或报告摘要。
- 少装饰，少阴影，只在关键卡片上使用轻微阴影。
- 不使用紫色/蓝紫渐变、彩色光斑、装饰性圆球背景。

## 色彩

建议基础色：

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#f7f7f5` 或 `#ffffff` |
| 主要文字 | `#111111` |
| 次要文字 | `#555555` |
| 弱提示文字 | `#8a8a8a` |
| 边框 | `#e5e5e5` |
| 深色卡片 | `#1f1f1f` |
| 深色卡片文字 | `#f5f5f5` |
| 轻微强调色 | `#70d6bd`，只少量用于状态点或成功提示 |

## 字体与排版

- 中文标题要有力量感，允许使用极大字号。
- 正文字体保持清晰，不要过小。
- 页面标题可以使用超大黑体风格。
- 英文/代码/数据可以使用等宽字体。
- 不使用负 letter-spacing。
- 不用随视口宽度变化的字体大小。

建议：

| 元素 | 风格 |
| --- | --- |
| 顶部导航 | 简洁横向导航，黑白按钮 |
| 主标题 | 超大、粗体、黑色 |
| 副标题 | 中等字号、灰黑色、行距舒适 |
| 数据卡片 | 深色背景、圆角、等宽数据标签 |
| 按钮 | 黑底白字为主，白底黑字描边为辅 |

## 布局

- 桌面端优先使用左右分栏。
- 左侧放用户输入、模块标题、核心说明。
- 右侧放报告预览、研究摘要、数据卡片或状态面板。
- 顶部导航保持极简，不要复杂菜单。
- 页面不要堆太多卡片；卡片只用于单个工具、报告、状态面板。
- 不要把卡片套在卡片里。

## 组件风格

### 按钮

- 主按钮：黑底白字，圆角中等。
- 次按钮：白底黑字，浅灰边框。
- 按钮文字简短直接，例如“生成报告”“保存画像”“开始追踪”。

### 卡片

- 深色卡片适合展示：
  - 研究报告摘要
  - Agent 运行状态
  - 数据来源
  - 关键财务指标
  - 追猎者更新结果
- 卡片圆角不宜过大，建议 8-16px。
- 阴影要克制。

### 表单

- 输入框要大、清楚、留白足。
- 表单字段不要密密麻麻。
- 用户画像这类复杂表单可以分区，但不要做成花哨问卷。

## Path of Market 的具体应用

- 首页/工作台：使用大标题展示“Path of Market 市场之路”，右侧用深色卡片显示当前研究任务或最新报告。
- 深研室：左侧输入公司/行业和问题，右侧展示结构化报告。
- 追猎者：用深色状态面板展示追踪结果、更新时间、重要性。
- 锐眼：用黑白列表展示“机会 / 风险 / 噪音 / 待验证问题”。
- 研究日志：保持干净的列表和详情页，不做过度装饰。

## 前端实现约束

- 默认做响应式布局，但第一版优先保证桌面端体验。
- 不使用重度动画。
- 不使用复杂插画。
- 不使用彩色营销风 hero。
- 页面文案少而准，避免解释功能用法的大段说明。
- 任何前端任务开始前，都应先阅读本文件。
