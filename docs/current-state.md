## 系统现在能做什么

网页输入 → Java 异步任务 → Python `AgentRunner`：按问题/预兆完整读取相关原版方法并形成计划 → 模型循环调用六个逻辑工具（找报告、完整阅读与回查、行情、原页视觉、读方法、正文取数）→ 程序核查引用/覆盖/图表/预兆章节 → 写作与复核 → 网页展示章节、引用、财务/业务/研发图、行情图、预兆覆盖。底层八个工具。
