# 第五步：网页展示演示报告

任务编号：M0-5。状态：**已完成，2026-10-15 构建、真实链路及浏览器检查通过**。

## 做出了什么

```text
网页输入研究任务
  → 同源 POST /api/research/mock
    → Vite 代理转交 Java
      → Java 调用 Python /research/mock
    → 返回结构化演示报告
  → 网页展示标题、摘要、章节和演示标记
```

浏览器不直接访问 Python。网页展示实际返回内容，不在前端生成另一份报告。本轮沿用原有后端，没有接入模型、行情、真实资料或研究工具。

## 页面操作

1. 打开 `http://127.0.0.1:5173`。
2. 填写对象和问题，或点击“填入示例”。偏好与预兆可展开选择。
3. 点击“生成演示报告”，等待后端返回。
4. 右侧显示标题、摘要和全部章节，并标注“演示报告 · MOCK”。“查看研究任务”可展开返回的对象、问题、偏好和预兆。

“预览任务”仍只预览当前输入，不请求后端。修改输入会使旧报告失效，避免将旧结果当成新任务的报告。

当前报告的 `mode` 为 `mock`、`isMock` 为 true，真实来源与工具记录为空。页面明确显示未读取真实资料、未执行研究工具。

## 启动

在项目根目录的三个终端分别运行：

```powershell
.\scripts\start-agent.ps1
```

```powershell
.\scripts\start-server.ps1
```

```powershell
.\scripts\start-web.ps1
```

默认 Python 为 8000、Java 为 8080、网页为 5173，均只监听本机。分别按 Ctrl+C 停止服务。本节为独立调试方式；整套应用统一启动、检查与停止见 `sixth-step.md`，是否运行以实时检查为准。

Java 使用其他端口时，在启动网页的终端设置：

```powershell
$env:JAVA_SERVER_URL = 'http://127.0.0.1:8081'
.\scripts\start-web.ps1
```

该配置只决定代理目标，不改变 Java 自身端口；Java 需使用对应端口运行。环境变量在网页服务重启后生效。

## 等待、错误与取消

- 生成时显示等待状态，限制重复提交、示例填充和输入编辑。
- 可点击“取消并清空”，终止浏览器等待并清空页面，之后的过期响应不会覆盖新任务。取消不保证服务端任务已经停止。
- 成功或失败后恢复操作，失败可再次提交。
- 422 字段错误显示在对象、问题、偏好或预兆附近；选填区隐藏时会展开，字段恢复可用后定位错误。
- 连接、服务故障、超时及返回格式错误显示明确中文提示，不直接展示上游内部错误正文。
- 草稿和报告仍只在当前页面中，刷新会清空。持久化在后续阶段完成。

| 场景 | 页面处理 |
| --- | --- |
| Java 目标不可连接 | 代理返回 503 `SERVER_UNAVAILABLE`，提示应用服务不可连接 |
| Python 不可连接 | 503 `AGENT_UNAVAILABLE`，提示研究服务暂时不可用 |
| 研究服务超时 | 504 `AGENT_TIMEOUT`，提示超时并可重试 |
| 上游状态或结果异常 | 502 `AGENT_ERROR` / `AGENT_INVALID_RESPONSE` |
| 非法 JSON / 字段校验 | 400 提示请求问题；422 映射字段错误 |
| 浏览器完整等待超时 | 15 秒后终止等待并恢复操作 |
| 非 JSON、错误报告或演示标记缺失 | 拒绝作为报告展示 |

Java 默认研究响应等待上限为 10 秒，浏览器完整等待上限为 15 秒，代理等待上限为 20 秒。等待范围包含响应正文，相关定时器和取消监听会在请求结束时清理。

## API 与代理

`src/api/research.ts` 发送既有四个字段：`target`、`question`、`userStyle`、`omens`。后端仍做最终校验。

客户端识别既有 mock 报告格式：明确的演示标记、字符串字段、预兆、章节，以及为空的来源/工具记录。不符合当前演示契约的内容不会显示为成功报告。报告文本通过 React 文本节点展示。

Vite 的开发服务器和生产预览服务器均代理 `/api`，保持路径不变，默认转发到 Java `http://127.0.0.1:8080`。代理连接失败返回结构化错误；已经关闭的浏览器响应不会被再次写入。

实现依据：[Vite 代理配置](https://vite.dev/config/server-options.html#server-proxy)、[AbortController](https://developer.mozilla.org/en-US/docs/Web/API/AbortController)。本轮未新增项目依赖。

## 验收结果

- TypeScript 类型检查与 Vite 生产构建通过。
- 三个服务健康检查、网页同源 API 和实际 Java/Python 报告通过。
- 24 组 Chrome 浏览器检查通过，覆盖本地校验/预览、真实报告与中文参数、任务详情、Unicode 边界、修改后失效、等待、防重复、取消和过期响应保护。

- 另两组代理检查通过：实际不可连接的 Java 目标返回 503 且网页可恢复；生产构建页面通过预览代理生成并显示真实后端的演示报告。
- 临时故障与生产预览进程已关闭；常规三个服务保留运行。
