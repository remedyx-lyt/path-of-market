# 三栏工作台与可见对话

2026-10-25。按用户反馈重做报告后的布局，保留现有黑白风格和React→Java→Python职责；没有重生成报告或收费追问。

## 使用方式

- 左侧“研究设置”独立展开/收起，报告页默认收起；表单与研究参数仍保留。
- 报告和对话分别滚动，均可收起。右侧“放大对话”可独占内容区，“并排查看”恢复报告。
- 桌面拖动中间分隔线向左即可增大对话。分隔线可键盘聚焦，左右方向键每次调整32像素，Home恢复默认。宽度随可用区域限制，不挤出页面。
- A−/A＋调整报告/聊天文字14–22px，保存本机阅读偏好；窗口变窄时改为报告/对话切换，输入框保持在底部。没有禁止浏览器缩放。
- 用户发送后立即显示消息，不等待整个后台任务完成；Enter发送、Shift+Enter换行，中文输入法组词时Enter不误发。
- 回答逐段显示，生成中标注“尚未校验”；完整格式/引用校验通过后保存正式对话。执行记录默认折叠，来源链接可展开。用户向上读旧内容时不强制追随滚动。
- 完成后定位最新一轮的用户消息和答案开头。查看旧节点仍保留父链选择；有新回复时提供醒目的“查看最新回复”，不悄悄混入其他分支。

## 核心实现与学习入口

| 文件 | 作用 |
| --- | --- |
| `apps/web/src/features/research-lab/ResearchWorkspace.tsx` | 左栏开合、工作台总布局；设置只隐藏不销毁 |
| `ReportWorkbench.tsx` | 报告/对话开合、版本和分支、字号、发送后临时消息、最新回复入口 |
| `DiscussionMessages.tsx` | 用户气泡、助手正文、单一消息滚动区、真实进度草稿、最终来源与原地错误 |
| `PanelResizeHandle.tsx`、`panelLayout.ts` | 拖动/键盘调整、尺寸限制和本机展示偏好；不改变研究参数 |
| `apps/web/src/styles/global.css` | 全高布局、窄窗口与低高度适配，不依赖350px固定侧栏 |
| `apps/agent/app/services/discussion_context.py` | 从流式JSON安全提取answer完整字符；处理反斜线、Unicode和半个代理对，最终仍完整校验 |
| `report_discussion.py` | 使用既有DeepSeek SSE回调更新`job.followup.draft`，校验失败撤回草稿，保存正式回复；按本次来源基线检查补查增量 |
| `research_recovery.py` | 保存补查基线，重试时区分旧问题与新问题 |

调用关系：发送→React立即显示用户消息→Java转发Python→既有模型SSE→只提取answer文字→原任务轮询返回`followup.draft`→聊天更新→最终引用/结构校验→JSONL追加→正式回复。不是前端打字动画；没有新增工具或另造Agent框架。模型输入/工具循环/检查点继续沿用已有Pi式父链和原生工具协议。

长报告组件使用memo，聊天每次进度轮询不重新渲染整份报告与图表；切换版本仍正常更新。原图表、标签开关、完整研究过程入口保留。
