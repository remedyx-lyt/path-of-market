# 数据来源

## MVP 策略

第一版先从上传文件、网页搜索、简单的免费或低成本行情数据开始。不要在第一版尝试复刻 Bloomberg 或 Wind。

## 可能的数据源

| 数据源类型 | 例子 | 说明 |
| --- | --- | --- |
| 上传文件 | 财报 PDF、研报、个人笔记 | 最适合早期 RAG 功能 |
| 公开公告 | SEC EDGAR、交易所公告 | 来源质量高，但需要解析和清洗 |
| 免费行情 API | yfinance、Alpha Vantage、Finnhub | 适合学习和原型验证，需要注意额度和条款 |
| 中文市场工具 | AkShare、Tushare | 适合 A 股数据，稳定性和权限需要评估 |
| 付费 API | 金融数据供应商 | 等 MVP 证明有用后再考虑 |

## 架构原则

所有数据源都应该通过 Data Provider 封装。这样以后更换数据源时，不需要重写深研室、追猎者、锐眼这些工作流。

第一版中，Data Provider 优先放在 Python Agent 服务里，因为 Python 更适合处理行情库、文档解析、RAG 和数据清洗。Java 主后端只关心“我要什么数据/研究结果”，不直接绑定具体数据源。
