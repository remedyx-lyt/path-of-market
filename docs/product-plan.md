# Path of Market（市场之路）产品规划

## 定位

Path of Market（市场之路）是一个基于大模型的个人财经研究工作台，内部包含研究 Agent。它帮助用户研究公司和板块、追踪市场变化、沉淀个人研究记忆，并发现个性化机会或风险线索。

Path of Market（市场之路）不替用户做投资决策。它只辅助研究和决策前的信息准备。

第一版通过本地网页使用。用户在同一工作台选择研究对象、资料和视角，系统传递相关上下文、调用研究工具并保存后续记录；目标是减少重复准备并使研究持续积累。

## 核心模块

| 模块 | 定位 | 第一版功能 |
| --- | --- | --- |
| 用户画像 | 让系统记住用户 | 投资风格、关注板块、观察池、风险偏好 |
| 板块地图 | 建立行业认知 | 产业链、核心公司、关键指标、催化因素、主要风险 |
| 深研室 | 公司和行业深度研究 | 研究报告、文档整合、反方检查 |
| 追猎者 / Pathfinder | 追踪市场变化 | 先做手动检查，后续加入定时任务 |
| 锐眼 / Deadeye | 个性化信号发现 | 根据用户画像筛选重要变化 |
| 研究日志 | 长期研究记忆 | 保存报告、假设、来源和后续问题 |

## 技术架构

| 应用 | 技术 | 职责 |
| --- | --- | --- |
| `apps/web` | React + Vite + TypeScript | 操作台界面、表单、报告展示 |
| `apps/server` | Java + Spring Boot | 主后端、数据库、业务 API、任务管理 |
| `apps/agent` | Python + FastAPI | LLM、RAG、文档解析、工具调用、Agent 工作流 |

Java 主后端是系统中枢，Python Agent 服务是智能能力模块。前端通常只调用 Java 主后端，Java 再按需要调用 Python Agent 服务。

## 深研室子模块

| 名字 | 作用 |
| --- | --- |
| 秘术师 | 做公司和行业的系统性深度研究 |
| 编年者 | 整理研报、财报、公告、新闻和时间线 |
| 审判官 | 寻找风险、矛盾和反方论点 |
| 探矿者 | 从资料中提取值得继续研究的线索 |

## 研究报告预兆

深研室生成研究报告时，可以选择 0 个、1 个或多个“预兆”来改变报告侧重点。预兆不是投资建议，而是报告生成前的研究视角控制。

| 预兆 | 侧重点 |
| --- | --- |
| 崇高预兆 | 深入解读公司、行业、商业模式、财务质量和竞争格局 |
| 远古预兆 | 更侧重历史周期、相似案例、行业演化和公司关键转折 |
| 机遇预兆 | 更侧重未来变化、潜在催化、趋势展望和情景推演 |
| 深渊回响预兆 | 更侧重风险端、反方论点、关键假设脆弱点和最坏情景 |

详细设计见 `docs/report-omens.md`。

## 分阶段实现

实施顺序以 `task-board.md` 为准：M0 Python 服务骨架、M1 真实研究 Agent、M2 Java 与网页接入、M3 研究积累与特色功能。先用少量真实资料验证研究循环，再扩展资料范围和工作台能力。

第一步的范围见 `first-step.md`。Mock 报告只属于接口准备，不算真实研究能力完成。

研究 Agent 必须根据目标和已取得的证据选择后续动作，并输出真实来源和执行记录。四个预兆是研究策略，不要求四个独立模型。

## 产品完整研究闭环

1. 用户创建自己的画像。
2. 用户让深研室研究一个公司或板块。
3. Path of Market（市场之路）调用 LLM 和必要工具。
4. Path of Market（市场之路）生成结构化研究报告。
5. 报告保存到研究日志。
6. 后续追猎者检查相关更新。
7. 锐眼判断哪些更新对这个用户更重要。
